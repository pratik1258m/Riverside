## ✨ Features

- **📱 Mobile-First Layout**: Fully fluid grid system ensuring optimal viewing on mobile, tablet, and widescreen monitors.
- **🎨 Luxury Real Estate UI**: High-contrast, premium color palettes (rich dark headers, refined borders, and polished layouts) matching the brand's aesthetic.
- **⚡ Performance-Optimized**: Lightweight static assets and optimized clean CSS ensure extremely fast load times.
- **🔍 SEO Ready**: Structured semantic HTML tags, clean page sections, robots.txt, and sitemap.xml for search engine crawlers.
- **✉️ Contact & Lead Generation**: Fully responsive contact forms and call-to-actions placed strategically to convert visitors.

---

## 🛠️ Technology Stack

- **Structure**: HTML5 (Semantic elements)
- **Styling**: Vanilla CSS3 (Custom styling grid system, hover transitions, and dark themes)
- **Scripting**: Vanilla JavaScript (Interactive sliders, responsive navbar, and animation triggers)

## 🚀 Getting Started

To run or view this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pratik1258m/Riverside.git
   cd Riverside
   ```

2. **Open in Browser:**
   Simply open the `index.html` file in any modern browser, or run:
   ```bash
   npx live-server
   ```
